# 📚 Temarios y Objetivos de Aprendizaje 2025

Para obtener estas certificaciones, el equipo debe dominar los siguientes dominios técnicos. Esta guía resume qué estudiar específicamente para cada examen.

---

## 1. Cloud Architects (Nube)

### 🟠 AWS Certified Solutions Architect - Associate
* **Diseño Resiliente:** Arquitecturas de múltiples capas, Amazon S3 (clases de almacenamiento), auto-scaling y AWS Lambda.
* **Seguridad:** VPC (Subnets, Security Groups, NACLs), AWS IAM (Políticas y Roles), y cifrado de datos (KMS).
* **Base de Datos:** Diferencias entre RDS (Relacional), DynamoDB (NoSQL) y Aurora.
* **Costos:** AWS Budgets, Savings Plans y optimización de instancias.

### 🔵 Azure Administrator Associate (AZ-104)
* **Identidad:** Azure Active Directory (Entra ID), RBAC y gobierno de suscripciones.
* **Redes:** Virtual Networks (VNET), Azure DNS, Load Balancers y VPN Gateway.
* **Almacenamiento:** Azure Blob Storage, Azure Files y herramientas de replicación.
* **Computo:** Configuración de VMs, Azure App Services y contenedores (ACI/AKS).

---

## 2. Infraestructura y DevOps

### ☸️ Certified Kubernetes Administrator (CKA)
* **Arquitectura:** Instalación de clusters con `kubeadm`, gestión de ETCD (Backup/Restore).
* **Workloads:** Gestión de Pods, Deployments, Rolling Updates y Rollbacks.
* **Networking:** Servicios (ClusterIP, NodePort), Ingress Controllers y Network Policies.
* **Troubleshooting:** Análisis de logs, fallos en el Control Plane y problemas de red en nodos.

---

## 3. Ciberseguridad

### 🛡️ CompTIA Security+ (SY0-701)
* **Amenazas:** Tipos de malware, ataques de ingeniería social (Phishing, Vishing) y vulnerabilidades Zero-day.
* **Arquitectura:** Principios de "Zero Trust", seguridad en la nube y entornos híbridos.
* **Operaciones:** Gestión de incidentes, escaneo de vulnerabilidades y herramientas forenses básicas.

### 🔐 CISSP (Nivel Senior)
* **Gestión de Riesgos:** Cumplimiento legal, ética y marcos de trabajo (ISO 27001, NIST).
* **Seguridad en el Desarrollo (SDLC):** Pruebas de seguridad estáticas (SAST) y dinámicas (DAST).
* **IAM:** Protocolos de autenticación (SAML, OAuth, OpenID Connect).

---

## 4. IA y Datos

### 🐍 Python Institute (PCAP)
* **Lógica Avanzada:** Manejo de excepciones, generadores, iteradores y decoradores.
* **OOP:** Herencia, polimorfismo y encapsulamiento profundo.
* **Librerías:** Manipulación de archivos, módulos `os`, `sys`, `datetime` y `math`.

### 🧠 LLM & LangChain (Frameworks)
* **Promp Engineering:** Chain of Thought, Few-shot prompting.
* **Arquitectura RAG:** Uso de bases de datos vectoriales (Pinecone/Chroma), Embeddings y recuperación de contexto.
* **Agentes:** Creación de agentes autónomos que usan herramientas externas.

---

## 5. Calidad y Agilidad

### 📋 ISTQB (Foundation Level 4.0)
* **Fundamentos:** Psicología de las pruebas, priorización basada en riesgos y niveles de prueba (Unit, Integration, System, UAT).
* **Técnicas:** Caja Negra (Partición de equivalencia, Valores límite) y Caja Blanca (Cobertura de sentencias y ramas).
* **Automatización:** Beneficios, riesgos y selección de herramientas.

### 🏃 Certified ScrumMaster (CSM)
* **Roles:** Responsabilidades del Scrum Master vs Product Owner vs Developers.
* **Eventos:** Facilitación de Daily, Sprint Planning, Review y Retrospectiva.
* **Artefactos:** Gestión del Product Backlog, Definition of Done (DoD) y Definition of Ready (DoR).

---

## 💡 Recomendación para el estudio
Para los exámenes de **Cloud**, se recomienda un enfoque **70% teoría / 30% laboratorios**. Para **CKA (Kubernetes)**, el enfoque debe ser **20% teoría / 80% práctica en terminal**.
